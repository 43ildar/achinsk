# Публикация игры «БЕГАЧ — Подслушано в Ачинске» во ВКонтакте

В этой папке (vk) лежит готовая к загрузке версия игры:

```
vk/
 ├─ index.html        — сама игра (вся логика внутри одного файла)
 ├─ lib/
 │   └─ index.umd.js  — библиотека VK Bridge (теперь лежит рядом с игрой,
 │                      а не грузится из интернета — это требование модерации VK)
 └─ README-ПУБЛИКАЦИЯ.md — эта инструкция (её загружать на сервер НЕ нужно)
```

## Шаг 0. Создать архив
Сделайте архив СОДЕРЖИМОГО папки vk (два элемента: index.html и папку lib),
а не самой папки vk. В Windows: откройте папку vk → выделите index.html и lib →
ПКМ → «Отправить» → «Сжатая ZIP-папка». Имя архива, например: achinsk.zip

## Шаг 1. Зарегистрировать мини-приложение
1. Откройте https://vk.com/apps?act=manage (нужна страница или сообщество,
   либо ваше приложение от имени пользователя).
2. Нажмите «Подключить приложение» → выберите тип «Веб-сайт» (мини-приложение).
3. Укажите название («БЕГАЧ — Подслушано в Ачинске»), категорию «Игры».

## Шаг 2. Настроить приложение (раздел «Настройка»)
1. **Тип приложения**: «Открытая платформа» → «Мини-приложение».
2. **Адрес сайта / Base URL**: адрес HTTPS-сервера, куда вы загрузите файлы
   (например, https://achinsk.example.com/). Игра откроется по индексу index.html.
3. **Разрешённый домен** — должен совпадать с адресом выше.
4. Загрузите иконку (192×192) и обложки для магазина приложений.

## Шаг 3. Хостинг (куда положить файлы)
VK требует HTTPS на собственном домене. Подойдёт любой статический хостинг:
VK Cloud, Netlify, Vercel, GitHub Pages (с включённым HTTPS) и т.п.
Загрузите туда содержимое папки vk (index.html + папку lib).
Сервер должен отдавать файл по адресу вида https://ваш-домен/index.html

## Шаг 4. Рекламные форматы и платежи (разделы настроек)
- **Монетизация → Реклама**: создайте форматы «Rewarded» (второй шанс / удвоение
  монет), «Interstitial» (между забегами) и «Banner» (в меню). Игра сама их
  запрашивает; без созданных форматов реклама просто не будет показываться.
- **Монетизация → Платежи**: включите платежи, чтобы работали покупки в магазине
  (скины, монеты, отключение рекламы). На iOS покупки через VK недоступны —
  игра корректно сообщает об этом пользователю.

## Шаг 5. Тестирование
1. В разделе «Тестирование» добавьте свой ID в тестировщики и включите
   «Тестовый режим».
2. Откройте приложение по ссылке vk.com/app{ID} — проверьте: запуск, прыжки,
   сохранение рекорда между запусками (облачное сохранение через VK Storage),
   магазин, рекламу и шеринг.

## Шаг 6. Отправка на модерацию
1. Заполните описание, скриншоты, категории.
2. «Отправить на модерацию». Частые причины отказа: внешние CDN-скрипты
   (мы их убрали — всё локально), отсутствие HTTPS, неработающие кнопки.

## Что уже сделано в коде для публикации
- Убран единственный внешний скрипт (unpkg): VK Bridge теперь подключается
  локально — файл lib/index.umd.js.
- Исправлена ошибка пути к библиотеке (было бы «vk/lib/lib/index.umd.js»).
- Облачное сохранение прогресса отправляется во VK быстрее (4 сек вместо 20),
  чтобы прогресс реже терялся при быстром закрытии игры.
- Игра полностью автономна: графика рисуется кодом, звуки синтезируются,
  никаких картинок/шрифтов/аудио с чужих серверов не грузится.
